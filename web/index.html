fairshoe verifier

Checks records of provably fair rounds and card shoes against the pair you kept before sending your client seed and against your own records. Everything runs on this page: it loads nothing and sends nothing, so it works offline.

    What to give
    

    All files and the pasted text together make one bundle of one seed pair. A file is a bundle with any of the keys below, or one record as the server hands it out (a round proof, a shoe record, a pair's reveal, its record list), or an array of records.
    

    

    keptthe pair as it was shown before you sent your client seed (seed id, game, server seed hash, root, commitment time), with the client seed you sent and the time the server set it
    

    ownyour own records of the pair: the proof ids and shoe ids you received, the nonce you last saw, the cuts you asked for, the hands you saw dealt, the table of each round
    

    seedthe pair's reveal, after the rotation
    

    proofsthe pair's round proofs
    

    shoesshoe records, each { "commit": …, "reveal": … }
    

    pairsyour other kept pairs of the game (earlier pairs whose shoes dealt rounds of this one)
    

    laterproofs of later pairs dealt from this pair's shoes after the rotation
    

    recordsthe server's list of the pair's proofs and shoes
    

    

    provable: the check is ok and bound to what you kept. ok: the records agree with each other, but something only you know is missing (the page lists it); the server could have chosen it. failed: the records contradict each other or what you kept. pending: not checkable yet (a shoe still in play, a pair not revealed).
